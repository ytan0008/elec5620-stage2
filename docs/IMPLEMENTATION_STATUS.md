# Stage 1 to Stage 2 implementation status

Source: `ELEC5620_Wed_09-11 Group3.pdf`, especially the use case specifications on pages 25–37 and the UC9 states on page 47. The implementation follows the four agent roles (Learning Coordinator, AI Tutor, Assessment & Analytics, Quality Manager) and the human instructor. Stage 1 assumes calibrated model confidence; this system treats confidence as an uncalibrated self-report. TOEFL uses the January 2026 1–6 section scale.

The system runs in two engine modes. **REAL**: an OpenAI-compatible model (configured with `OPENAI_API_KEY`, optional `OPENAI_BASE_URL`) generates conversation, examiner follow-ups, new tests and rubric feedback, with optional cloud speech. **LOCAL** (no key): a curated exam-format test bank, a rule-based rubric analyser, a scripted examiner, a rule-based tutor and a bundled ECDICT dictionary subset. Every generated result passes the same quality gate in both modes. The default cloud model is `gpt-6-luna` (Responses API; reasoning effort none for conversation, low for scoring). Each agent has its own memory (`agent_memories`) and a tool set for its module, chosen by the model in a bounded tool-calling loop; tool calls and memories are visible in the teacher console. Fine-tuning is not used.

|---|---|---|
| UC1 Register/profile | Sign-in-first entry; minimal sign-up; voice- or text-guided Coordinator interview; confirmed profile and quality-checked learning portrait; profile editing; one-time password reset; switchable pixel avatar (witch / boy) stored per account | Email verification; persistent recovery rate limits |
| UC2 Plan | Coordinator StateGraph with rationale, weekly activities, change requests, accept/reject, active plan and dashboard quests | Plan quality evaluation with real learners |
| UC3 Speaking | Live spoken examiner: IELTS Part 1 → Part 2 cue card (1 min prep, 2 min talk) → Part 3, or TOEFL Listen & Repeat + Interview; hands-free turn-taking with browser speech recognition (cloud transcription optional); spoken examiner voice; session recording and replay; fluency metrics (speech rate, fillers, turn length); free voice conversation; quality-gated feedback | No acoustic pronunciation scorer (pronunciation is never scored from a transcript) |
| UC4 Writing | Task 1 with rendered bar/line/pie charts, Task 2, TOEFL email and academic discussion; timer, word count, autosaved drafts; criterion scores, sentence-level corrections, rewrites, model answer (REAL mode); revision history with score change; comparison with the previous attempt (issues fixed / still present, criterion changes) | Inline prose diff between attempts |
| UC5 Mock | Short (~90 min) or full-length (~2 h 45 min) computer-delivered mock: multi-speaker listening played once, three reading passages, both writing tasks, live speaking examiner; persistent timer, autosave, section scores and detailed review; dictionary and tutor locked server-side while running. The Assessment & Analytics agent prepares the mock (one retry, then "temporarily unavailable"), scores writing and speaking against the rubric (one retry; an unscored section holds the result for the teacher with the answers kept), names strengths and weaknesses against the target, compares with the previous mock and estimates readiness from the gap and trend. A mock needs one verified practice result first. As in the real test, blank listening, reading or writing answers do not stop marking (they count as wrong, with a reminder before submitting); only a mock ended or abandoned before the speaking test is recorded as incomplete with no result, and one that runs out of time after the speaking test is marked; a marked mock triggers UC7 adaptation | Validated band conversion against official papers; inter-rater reliability measurement |
| UC6 Reports | Verified-only skill charts and history, weak/strong skills, repeated issues, saved quality-checked reports, knowledge graph overlay; notebook statistics showing which question types and grammar issues recur. The Assessment & Analytics agent analyses progress (one retry) and writes the report: strengths at or above the target and weaknesses below it never overlap, per-skill trends (improving, steady, declining, or "not enough data"), one readiness rule for the page and saved reports, recommendations from gaps, declining skills and repeated problems; if recommendations fail the report is kept without them; unavailable data shows a retry message; "Recommended for me" opens UC10 | Predictive calibration; concept-level mastery |
| UC7 Adaptation | Three triggers share one flow (`backend/adaptation.py`): learner request, weekly review and a completed mock exam (UC5). 3a: fewer than two verified assessments keeps the plan and tells the learner. The proposal compares the active plan with verified scores and lists each major change (priority, weekly minutes) with its own rationale; the changes are computed, the model supplies the wording. 4a: one retry, then the existing plan is kept and the learner is told. 5/5a: one study resource per top priority, or the area shown without a recommendation. 6a/7a: change requests and rejection keep the existing plan. 8/8a: confirming activates the plan and delivers the new priorities to the AI Tutor and Assessment & Analytics; a failed delivery is logged, retried and never rolls the plan back | Deployed scheduler; a revised plan (6a) does not carry per-change rationales; notifications are in-process memory writes, not an external channel |
| UC8 Human review | Review queue with evidence, confidence, approve/correct/request information, decision history and audit; teacher developer console with live agent trace, anomaly detection (model failures, provider outages, holds, latency, score drops, curriculum gaps, inactivity) and learner issue reports with replies | Multi-instructor assignment; notification delivery |
| UC9 Quality | Structured, threshold, rubric-key, score-range and consistency checks; generated tests must have every completion answer supported by the script/passage; durable hold/release; adjustable threshold with audit | Empirical false positive/negative rates |
| UC10 Materials | Strategy lessons per skill, filters, relevance feedback, quality-checked recommendations; structured question bank (IELTS listening parts, reading passages, writing tasks, speaking tests, TOEFL 2026 set), AI task generation, official sample links | Licensed official content |

Learning support added beyond Stage 1: an AI tutor with long-term memory (facts, goals, difficulties, verified progress, editable by the learner) and "Coach me" plans; a Mistake book (wrong answers by question type, retry and spaced review), Word book (select any word or tell the tutor; offline phonetics and Chinese meanings; flashcards and chat quizzes), Grammar book (feedback errors with combined corrections) and Sentence book (rewrites and saved sentences tagged by structure). During tests a selected word can be saved but its meaning stays hidden until the test ends.
